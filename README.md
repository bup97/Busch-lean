# Busch LEAN

Lean-Werkzeuge für Prozessanalyse in einer App: Wertstrom (Ist/Soll mit Kennzahlen und Checkliste), Verschwendung, Zeitaufnahme, Spaghetti-Diagramm, Greifraumanalyse, Ishikawa, 5-Why, 5S-Audit, Maßnahmenplan und Notizen – jeweils mit Kurzanleitung.

Läuft als Progressive Web App über GitHub Pages. Daten bleiben lokal im Browser; über Export/Import auf der Startseite sichern.
